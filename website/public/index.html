01.1

Your servers, now tools.

Tamio runs an MCP server on your Mac. Agents can check live load, run commands and manage your hosts using your saved connections.

One command to connect. No credentials to hand over.

claude mcp add tamio -- /Applications/Tamio.app/Contents/Resources/tamio-mcp
Codex and other MCP clients use the same executable. Install the Tamio skill from Settings › MCP to teach your agent the rules.

02 / NOTHING LOST BETWEEN SESSIONS

Sessions end.
The history stays.

Every operation has a record: which agent, which Mac, what ran, and what came back.

Switch agents or devices. The next agent can read what the last one did and pick up right there. Agents use get_activity before starting, and log_activity to record work done over their own SSH.

03 / TRUST IS BUILT IN

Agents get the work.
Never the keys.

Your connections belong to you.
Tamio keeps it that way, by design.

Secrets only go in

No tool returns passwords, private keys or passphrases. Agents only get the public half of a generated key.

Local means local

A Unix socket only your user account can open. No network port, no exposed MCP server.

Host keys checked

Trusted on first use, checked on every connection. Changed keys are refused before a password is sent.

Encrypted on disk

Servers and identities stay encrypted under a key held in your Mac's Keychain.

Private across devices

Data is encrypted on your Mac before it reaches iCloud, with a passphrase only your devices know.

Open to inspection

MIT licensed. Apple-notarized releases. Verified updates. Read every line on GitHub.
